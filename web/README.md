# web

React + TypeScript + Vite frontend for QanoonDaan.

- **Start here:** [HANDOVER.md](./HANDOVER.md) explains how to run it, how it is organised, and how to add features.
- **Backend spec:** [BACKEND-CONTRACT.md](./BACKEND-CONTRACT.md) lists every endpoint and table the UI expects.

Quick start:

```bash
cd web
npm install
copy .env.example .env.local     # keep VITE_USE_MOCK=true until the backend exists
npm run dev                      # http://localhost:5173
```
